# 2026-10-28 — X2: does A1 (region-free re-detection) make the belief right at grasp / place time, event-triggered (J) or always-on (S)?

Streams C (harness, data) and W (A1). Reviewer: the perceptor architecture review. Scorer: stream M's grasp-time
metric. Journal: [../journal/2026-10-28-dojo-bgperc.md](../journal/2026-10-28-dojo-bgperc.md) §7.

## Question

A1 (stream W, `dojo.runtime.tick` + `dojo.perception.redetect`, behind `RuntimeConfig.a1`, default off) re-detects
objects with the twin-trained segmenter at decision points. It writes the belief when the evidence beats the
incumbent pose.

- Does it raise the share of clean grasp / place events over the runtime's own belief (rt)?
- Is ticking on every frame (S, always-on) worth more than ticking at the events (J)?

The second question is Ilia's background-perception question, asked a second time with a real re-detector.

**Pre-registered rule** (lead, before the run): *always-on is worth building online only if S − J ≥ 3 points of
clean@R10 on the X2 events, with S's broken ≤ J's broken (verdicts against the per-writer p95).*

## Protocol

This is the reviewer's design, adopted by the lead. The harness is `scripts/perception/bgperc/x2_eval.py`, the one
official harness. W's `scripts/perception/a1/x2.py` stays a dev tool.

- **rt = the recorded belief.** It comes from M's `episode_events`: the runtime's `dev_belief_probe` at every gripper
  change, plus the logged writes.
  - It is exact, consistent with the replayed actions, and needs no recompute.
  - Its counts equal M's scorer on the same runs.
- **An arm = the recorded belief + that arm's writes, computed on the stored frames.** Labels the arm wrote follow a
  causal chain:
  - every later recorded write of such a label is re-run on the stored frame of its step from the arm's pose
    (`write_rerun.py`, the service's own `_Perception.refine`). The writes are pick / place / held refines and
    post-place re-measures;
  - the re-run is adopted by the runtime's main gates;
  - writes that would need a re-hover, a second view or the post-place head-view confirm cannot happen offline (the
    actions are fixed). They are not adopted and are counted as **offline-blind**;
  - closes attach by M's `attach_label` on the arm's belief, and releases leave the object where the jaws let it go;
  - untouched labels replay as recorded.
- **A1** = `tick.run` from **`dojo-a1-frozen-v1` (fe15d48), imported unchanged**, mode apply, `RDConfig()` /
  `TickConfig()` defaults. The inputs are built as online (W's interface):
  - tick points / triggers (`triggers_from_events`), `fixture_labels`, `rose_evidence`, lift;
  - q_path = every 3rd executed action since the arm's last tick;
  - held_path per carry segment, from the arm's own jaw log (`held_path_from_log`);
  - corridor at hovers, close_tcp at empty closes.
  - **J** ticks only at W's triggers (missed close / slip, release, lift, hover).
  - **S** ticks at J's ticks plus `Trigger("periodic", s)` on every stored frame (stride 2 + the decision frames). One
    TickState per episode.
- **Detections: one frozen cache for both arms.**
  - `x2_eval.py --prepare-dets` runs v2b on the 3 cameras of every stored frame, on CPU, into W's `DetSource`.
  - Model id `seg_v2b`, imgsz 960, conf 0.25, weights sha1 1a8bc5d4522c.
  - A cache miss is an error: there were 0.
- **GL**: EGL on compute4's GPU, never the CPU fallback.
- **Code**: the tag's refine path reproduces the recorded runs' code exactly (16/16 writes identical on
  tools_gcon_100000).
- **Scoring**: stream M's `score_event` + held metas + root causes (`m95_score.py`'s functions), GT at k-1 from
  `gt.jsonl`, rows in M's `events.jsonl` format per arm. M's `m95_score.py x2 --split` scored the same output
  independently and matches exactly (517 paired, 0 unpaired).
- **Noise floor**: render noise. RTX frames differ from run to run (about 65 % of pixels, mean |Δ| 0.45 levels).
  - Each recorded write is re-run from its recorded prior on the replay's frame and diffed against the logged result
    (`write_rerun.py`, fidelity mode).
  - A fixed / broken verdict counts only if the arm's belief change for that object exceeds its writer's p95. Below
    that it is "within noise".
  - **The floor used is INTERIM**: 12 ON episodes, 2 each of bottles, bowls, organize, sweep, tools and ttt (no swap):

| writer | writes | ok decisions agree | both ok | Δpos p50 / p95 / max (mm) | Δrot p50 / p95 (deg, symmetry-aware) | > 2 mm |
|---|---|---|---|---|---|---|
| refine_pick | 63 | 63 / 63 | 45 | 0.6 / 8.8 / 17.2 | 0.2 / 8.1 (15 rows) | 14 |
| refine_place | 30 | 20 / 30 | 2 | 18.3 / 33.9 / 35.7 | — | 1 |
| refine_held | 23 | 21 / 23 | 2 | 0.9 / 1.4 / 1.5 | — | 0 |
| post_place | 38 | 37 / 38 | 6 | 0.4 / 8.8 / 11.5 | — | 1 |

  - Rotation uses M's symmetry rule (`grasp_metric._rot_err`). A tool flipped 180° is a real pose error there.
  - Place refines are noisy: 10 of 30 ok decisions flip. Every flip is on the bowls' / tic-tac-toe board's supports,
    the recorded not-ok turning ok on the replay.
  - An A1 tick's own write is held to refine_pick's p95.

## Decision

- **Always-on (S): not built.** S − J = +1.4 points clean@R10 (S broken 1 = J broken 1), below the pre-registered
  3 points. The gain is all on put_bottles, at about 9× J's ticks, and partly confirmed by near-identical frames.
- **A1 event-triggered (J): to its rendered A/B** (the lead's spec to Integration). Offline it gains +2.7 points
  overall, +3.1 on the ON set, +9.6 on put_bottles and about 0 elsewhere, with 1 broken.
  - It stacks with H's drop-verdict fix: no overlap, see above.

## Caveats

- **Interim floor.** 12 episodes, no swap. Every R10 flip is far above the relevant p95, so the verdicts would not move
  under a fuller floor. The 2-hour phase-2 pass adds episodes and symmetry-aware rotation everywhere (journal).
- **Offline is not online.** The actions are fixed: A1 cannot change what the robot does. A belief corrected before a
  grasp would, online, re-plan that grasp; offline it is only scored.
  - Re-computed writes follow the runtime's main gates, not every branch (no re-hovers, second views or head-view
    confirms). Those writes are counted (offline-blind 4-5 per arm).
- **Render noise.** The stored frames are not the recorded run's pixels. For the re-computed writes the floor is the
  bound. A1's own fits are held to refine_pick's p95.
- **One harmful class.** The common broken event is a place whose reference / object A1 moved. It is listed in M's
  rows.

## What would change the answer

S's extra gain is bottles-only: bottles left on the table after failed or knocked grasps that event ticks reach later
than periodic ones. A task mix dominated by moving or knocked objects (more grasp retries, pushes, actors) could give
always-on more, and the rule should be re-read on such a mix. On these 7 tasks, nothing outside put_bottles moves.

## Reproduce

```bash

python scripts/perception/bgperc/replay_check.py ROOT --json ROOT/valid.json --seg-cache ROOT/dets_v2b

# noise floor (light slot, EGL, the recorded runs' code)
CODE=<8dae375 export> LOCK=<slot> scripts/perception/bgperc/write_rerun.sh ROOT --out fid.json --valid ROOT/valid.json --order task_rr --per-task 2
# the arms (the tag's code, the recorded runs' venv, EGL)
SCRIPT=x2_eval.py CODE=<dojo-a1-frozen-v1 export> PY=<8dae375 venv python> LOCK=<slot> DOJO_GL=1 \
  scripts/perception/bgperc/write_rerun.sh ROOT --arm a1 --arm-name J --schedule event --dets-dir ROOT/dets_v2b \
  --valid ROOT/valid.json --floor fid_interim.json --out-dir ROOT/x2        # S: --arm-name S --schedule always
python scripts/perception/bgperc/x2_report.py ROOT/x2 --arms J,S              # M: m95_score.py x2 ROOT/x2 --split '_(gcon|gcoff)_'
```
