# Instruction-only SAM round 2: latency recovered, phantom guards still fail

**Decision: NOT QUALIFIED. No camera preregistration, manifest or queue append.**
All 32 registered combinations were evaluated. The prospectively ranked closest is
**score>=0.5 only**: micro recall **68.5→89.6%**, macro **59.0→83.0%**, IoU
**0.638→0.832**, phantoms **11→78**, with **12/42** failing harm groups. Gains and
latency pass; phantom guards fail. This is evidence for joint planning, not adoption.

[Preregistration](2026-11-07-samint-r2-prereg.md) and [design](data/samint-r2/design.json)
were frozen on main at `bbbe53b4` before inference. Measured source `68cc25e8`;
[implementation PR #433](https://github.com/miilv/controlr/pull/433). A subsequent
packaging-only camera import fix makes matrix operations usable without optional
SciPy; it does not change the frozen projection/triangulation math or these results.
Runtime defaults remain unchanged and historical task banks remain diagnostic-only.

Data: [all 32 combinations](data/samint-r2/ablations.csv), [all cell/combination metrics](data/samint-r2/cells.csv),
[all 1,344 group checks](data/samint-r2/risk.csv), [verdict](data/samint-r2/verdict.json),

## What the geometry ablations can and cannot establish

One pure instruction parser plus **object/container/tool**, fixed globally;
no catalogue prompt sweep or task-keyed object phrases. Mask pairing considers
all pairs without semantic/task/identity pruning. Only the size check looks up
whole-catalogue label extents; unknown labels use the entire catalogue envelope.
No task config, checker, role, placement prior or GT reaches a predictor/filter.
Camera K/T and RGB masks are the only geometry observations. Source/calibration/GT
integrity hashes were frozen, with GT read for scoring after all filter decisions.

There is **no measured depth**. Centroid triangulation and planar silhouette bounds
are a support/size proxy, not measured physical contact/volume. Of **1,456**
self-deduplicated SAM masks, **772 (53.0%)** lack accepted geometry. Support rejects
1,145 total, including those 772 and 373 additional geometry-known masks. Size
rejects 839 total, including those 772 and 67 additional masks. These rejection
counts are masks, not independent object observations; the recall table measures
object-level cost. Egg loses 40 pp with multiview alone and 54.3 pp with support;
image conveyor loses 44.4 pp with support/size. This is not evidence that those
objects truly float or have impossible sizes.

Support/size require geometry; therefore enabling multiview alongside either is
redundant in this operational implementation. They are standalone filter arms but
not orthogonal physical measurements. The tables disclose this dependency rather
than attributing all lost recall to a contact/size judgement. True isolated support
validation needs better depth/geometry. v2b agreement costs 22.5 pp pooled recall and
vetoes precisely the novel SAM-only coverage; it is a poor general admission veto.

## Prompt and shared-server latency scaling

Prompt counts **6–13**, mean 8.5, median 7, versus 616–622 previously. One SAM3 server,
actual existing socket protocol, two simultaneous clients serialized by its lock.
Three single requests and two concurrent requests per camera/count on registered
prefixes of one maximum-count instruction; same RGB is reused and wire-cached,
while SAM's image encoder is run by each request. This controls prompt-count scaling,
not a dedicated whole-machine throughput comparison. Changing shared GPU load means
round1/round2 timing differences are descriptive, not a controlled hardware test.

Scaling is approximately 0.075s at one prompt, 0.25s at six, 0.49s at 13. At13 prompts,
worst two-client RPC time is 0.989s head / 0.972s left / 0.965s right. Thus the direct
shared-server RPC gate passes, with little wrist margin. Closest score-only full
frame p50 is **0.391s head /0.321s wrists**, maxima **1.063s /0.527s**. Head's max
includes the base detector's first-use cost. Multiview-dependent variants cost about
1.03s median and up to1.71s per wrist when peer requests are correctly charged.
Geometry CPU itself is only **0.027s median /0.055s max**; cross-view dependency,
not triangulation arithmetic, is the timing bottleneck. No free cached peer views
or unmeasured asynchronous speedup was assumed to pass the deadline.

no downloads/rendering. Server load 5.5s, peak torch allocated 5.40 GB; ready/warmup and
all raw timings are in meta.json. Probe wall time **198.75s (3.31 minutes)** including
scaling and all scoring. **256 local SAM requests, 180 v2b inferences; LLM calls,
tokens and spend all zero.** The owned child was terminated in finally; parent exited 0,
socket/lock released, no other PID touched.

## Joint planning and dispatch disposition

Keep the small instruction-only vocabulary and measure it as a general path. Retain
v2b-first dedup, but avoid a v2b-overlap veto on novel masks. The support+score frontier
justifies discussing better RGB/depth observability and generic background/part
reasoning. Missing geometry must be separated from evidence of bad support/size.
Reusing already-needed peer masks/features or scheduling a synchronized bundle may
reduce dependency cost, but neither is a measured latency win in this registration.
Any changed matching, threshold or filter combination requires a new prospective
registration; no after-the-fact tuning or per-task exception is adopted here.

No general camera preregistration or frozen camera manifest was created because
qualification failed. No egg refill, no camera calls, no SAMINT queue append, no
compute4 GPU process, no STOP removal; no compute6/7 work. Existing compute4 rows
remain untouched. This lever is not mixed into CLASSIFY3, COIN2, IMIT2, POUR or MATCH2.
The legacy task-prior fitter remains outside the task-free component boundary;
these offline masks alone do not establish end-to-end board compliance. All old
task routes/banks remain default-off and diagnostic-only.

Validation: full local suite **2,643 passed, 41 skipped** (17m07s); **21 focused
tests also pass in a clean minimal environment**, plus four existing camera rotation/
projection checks. [CI is green](https://github.com/miilv/controlr/actions/runs/42408715063);
implementation merge `3539749a409cb56fb8895bb99d58750c8059291c`.

At the final locked compute4 read (20:05:08Z), **120 pre-existing rows** were present.
SAMINT appended/reordered none. STOP inode/mtime remain unchanged. See the
