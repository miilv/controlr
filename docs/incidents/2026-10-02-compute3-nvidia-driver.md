# 2026-10-02 — compute3 без GPU после автообновления ядра

**Симптом:** `nvidia-smi` — «couldn't communicate with the NVIDIA driver»; Isaac Sim не стартует.
Машина перезагрузилась 2026-10-02 01:51 в ядро `7.0.0-34-generic`.

**Причина:** драйвер стоит как пребилт-модули Ubuntu `linux-modules-nvidia-595-open-<ядро>`;
были установлены до `7.0.0-31`, а для нового `7.0.0-34` пакет не поставился — мета-пакет
`linux-modules-nvidia-595-open-generic-hwe-24.04` отстал от ядра (7.0.0-31 при кандидате 7.0.0-38).
Secure Boot выключен, DKMS не используется.

**Как чинили** (с разрешения владельца, без ребута, ~3 мин):
`sudo apt-get install -y linux-modules-nvidia-595-open-7.0.0-34-generic && sudo modprobe nvidia nvidia_uvm`
→ RTX 5090, драйвер 595.91.07. Чужая CPU-джоба и сессия не пострадали.

**Что поменяли:** процедура в [RUNBOOK §1](../RUNBOOK.md); пункт в BACKLOG — обновить мета-пакет
вместе с ядром, иначе следующее обновление ядра повторит.

**Уроки:** на общей машине апдейты ядра приходят без нас; первым делом при «нет GPU» —
сравнить `uname -r` и установленные `linux-modules-nvidia-*`.
