## Full-run preparation contract

`baselines/rsi/prepare.py` uses only ids 100000–09 and 100020–29 with salt
`rsi-yardstick-20261107`. It selects the first ten stable inputs in ascending
id order before scoring; toast/conveyors use raw-check, other tasks use the
existing presettle + keep-raw-unmoved check. Imitation also requires validated
demos (demo speed 1.5), whose bytes are hashed. Short cells stop preparation;
there is no padding from another slice. Inputs, call order and SHA-256 hashes
are frozen before any yardstick score. Ports must consume the same bytes AND
call order because the official client seeds by call position.

Comparison caveat: the November 5 points-table journal explicitly describes
historical strict-valid board scores (51.53), not a newly scored paired D-C19
block. Do not mislabel that column. Published RSI seed-0/seed-2 Average Scores
87.16/85.36 use different layouts and episode counts, so are context only.

## Permission correction and restricted resumption

The initial compute7 brief used a permission revoked on 29 October. The lead
stopped launcher 794616 and its children, collector 801819 and power watcher
778795 at about 14:2xZ. No yardstick episodes had been scored. See the
[unauthorized-use incident](../incidents/2026-11-07-compute7-unauthorized-use.md).
The Phase 1 decision and six smoke results stand. No files were deleted.
A compute4/compute6 move was planned for after their camera lanes drain;
[the portable install recipe](../../baselines/rsi/INSTALL.md) prepares that
option without starting those boxes.

The lead subsequently superseded STOP with Ilia's new permission:
“Ilia now allows compute7 for PARTIAL use, as long as we don't get in the way
of the person who works on it”. Conditions: **one** Isaac+policy job (prep
shares the slot), approximately 16 GB VRAM; user scope CPUQuota=800%,
MemoryMax=16G; nice 10 and ionice class 3. Before every start, yield for five
minutes above foreign GPU memory 2 GB, foreign load1 8, or GPU power 300 W.
Admission logs conservatively treat all pre-start used VRAM and all load1 as
foreign, with zero guessed subtraction. They fail closed on telemetry errors.
Only recorded owned children may be signalled. Existing desktop processes
are untouched. No reboot services. Existing install and SAM3 stay in place;
writes remain in the two permitted RSI trees. The stale stop note is replaced
with a resumption record quoting the new permission.

The first pass now scores **five episodes per cell**, positions 0–4 of each
frozen ten, in the lead's gap-priority order: imitation, match-and-pick,
pour-by-language, classify-by-language, coin, classify, organize, bottles,
pens, eggs, image conveyor, then the remaining cells. Each cell freezes its
ten inputs before scoring; manifests append cells without changing already
selected bytes. Previously prepared checkpoints are verified and reused.
Closed cells publish an atomic incremental per-cell JSON; missing cells remain
null. This pass is 270 episodes, not the completed 540-episode yardstick.
The remaining five per cell and any compute4/compute6 lanes need a separate
request, retaining the original call positions 5–9.
