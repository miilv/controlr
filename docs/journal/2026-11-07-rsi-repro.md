Internal yardstick only. The upstream fixed programs remain in the isolated policy
installation, never in controlr policy code, and nothing is submitted.

  size 3,450,062,241 bytes; required SHA-256
  `9999e2341ceef5e136daa386eecb55cb414446a00ac2b55eb2dfd2f7c3cf8c9e`.
  The launcher refuses to start the smoke without that verification.
- RoboDojo installed commit `f57e1633ffed59761bc8e568cfe7530c4b33381c`;
  installed XPolicyLab `e08ba78888b233b77ed2bb2d92886a52360a1081`.

  `cb2a37d58dbbeb2777b0c2b30e97ecb8ab91095c`.
  Git diff against the installed RoboDojo changes only XPolicyLab's submodule
  pin and an optional articulation reset-drive feature. Task definitions and

  requires the end-to-end smoke; this source comparison alone is not parity.

Writes stay in `~/controlr-rsi-repro*` and `~/dojo-data/rsi-repro`.
A private RoboDojo symlink farm owns the policy registration and outputs;
shared installs are read-only. HOME, caches and TMPDIR are private. Runtime
uses `env -i` with an explicit allowlist, no dotenv, no inherited API keys.
RSI itself sets a local endpoint and a dummy `offline` credential.
Calls to external LLMs: zero. No other compute lanes are accessed.

Smoke: two fresh salted raw layouts (100020–21) for each of stack_blocks,
press_by_number and insert_tubes. A SHA-256 manifest records call position
and bytes. RoboDojo's own client is launched through `dojo.simlab.dev_eval`;
only layout loading is substituted. Output: `~/dojo-data/rsi-repro/smoke/`.

One Isaac+policy call at a time; a private flock serializes admission.
`power.log` records timestamp, GPU watts and MiB every five minutes. Starts
pause above 450 W or on failed telemetry. Only owned process-group PIDs are
stopped, recorded in each call's pid files. A duplicate telemetry startup
was detected and the extra owned logger stopped via its recovered PID file.
No power-limit/driver/system changes or reboot services.

## Full-run preparation contract

`baselines/rsi/prepare.py` uses only ids 100000–09 and 100020–29 with salt
`rsi-yardstick-20261107`. It selects the first ten stable inputs in ascending
id order before scoring; toast/conveyors use raw-check, other tasks use the
existing presettle + keep-raw-unmoved check. Imitation also requires validated
demos (demo speed 1.5), whose bytes are hashed. Short cells stop preparation;
there is no padding from another slice. Inputs, call order and SHA-256 hashes
are frozen before any yardstick score. Ports must consume the same bytes AND
call order because the official client seeds by call position.

Comparison caveat: the November 5 points-table journal explicitly describes
historical strict-valid board scores (51.53), not a newly scored paired D-C19
block. Do not mislabel that column. Published RSI seed-0/seed-2 Average Scores
87.16/85.36 use different layouts and episode counts, so are context only.
