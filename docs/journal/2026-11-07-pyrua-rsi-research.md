# PyRUA-RSI source teardown

Research stream RSI-TEAR inspected PyRUA-Lean e754cf43 through a depth-one,
blob-filtered temporary checkout. [Report](../../research/robodojo-teardown/pyrua-rsi.md)
covers evaluation wiring, sandbox enforcement, all requested gap cells and weak
cells, visible development evidence, and three integration options without
selecting one. The research index links it.

Key distinctions: evaluation is one offline Python cell, no LLM; fixed task
priors and termination-based failure inference deserve separate review from
runtime hidden-state access. Sweep picks objects into the pan, contrary to our
broom-only task ruling; kong uses a fixed identity table where we require glyph
reads. Neither is counted as transferable points. Existing pour/classify ports
are acknowledged, with camera and execution costs still unresolved.

Static analysis of all 54 programs found no blocked introspection names;
17 sources generate informational audit flags, which are not enforcement
failures. Eleven random siblings are byte-identical to standard; toast differs.
Total development episodes, hardware and complete search/selection history are
not released in the inspected tree. No performance was reproduced.

Validation: source citation ranges, local Markdown targets, ranking arithmetic
and git whitespace checked. No application code changed. No simulator/camera
jobs, model/media downloads, model installs or paid API calls; calls/tokens/spend
0/0/0. The temporary upstream checkout was deleted after verification.
