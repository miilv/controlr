# 2026-10-02 — ключевые решения по архитектуре v0

**Решения (и почему):**
- **Модель — контроллер, без скиллов и VLA.** Тезис проекта: большие API-модели с правильным
  промптом справляются; рекомендация литобзора «LLM выбирает скиллы» сознательно отклонена,
  альтернативы — только переключатели конфига.
- **Пошаговый цикл, а не реальное время.** Робот стоит, пока модель думает; ~1 с/ход — цель, не
  ограничение; длинный первый «обдумывающий» вызов допустим → отдельный планировщик
  (`claude/claude-opus-5-5-xhigh`), его текст идёт в первый ход.
- **Python с нуля, а не форк coding-харнесса.** Pi (TS, отличный слой провайдеров) потребовал бы
  мост к Python-стеку робота; Hermes (≈490 тыс. строк, сжимает историю) — слишком тяжёл и ломает
  append-only. На старте оценивали ядро в ≈1–2 тыс. строк (к концу дня весь пакет вырос до ≈8.8 тыс. с Isaac-бэкендом и safety); Pi и Hermes — как референс (размещение кэш-маркеров), код не заимствован.
  Rust не даёт выигрыша: ход упирается в сеть и модель (0.5–5 с), не в харнесс.
- **Один OpenAI-совместимый роутер (omniroute)** вместо SDK провайдеров; кэш Claude через него
  проверен (≈95 % чтения).
- **Isaac Sim со сценой PHANTOM, а не MuJoCo.** Откалиброванная копия реального стенда (UR3 CB3,
  Robotiq, D435) → выводы про промпт/представления переносятся на железо. MuJoCo-сцена брошена.
- **Действия по умолчанию — `ee_delta` в мм, ориентация фиксирована, захват бинарный**; остальное
  (`ee_abs`, joint-режимы, `rotation=yaw/full`, чанки) — оси конфига.
- **Контрол-модель по умолчанию — `claude/claude-sonnet-5-5`** (по просьбе Ильи; через роутер
  работает, хотя нет в `/models`).

**Не доделано:** см. [BACKLOG](../BACKLOG.md) P1 — камеры, коридор переноса, коллизии рука–коробка.
