# SAMINT: default-off camera task proposals and one shared SAM service

Implementation based on SAMBAKE #423 (`feat/sam3-task-prompts`, unmerged at start).
No candidate/default adoption, no LLM calls, no camera jobs/queue writes, no sealed data.
Only compute3 GPU work; no process on compute4/6/7 was started. PID 3613 was untouched.

The runtime adds `EstimatorConfig.sam_task_routes={}`: exact instruction-derived vocabulary
keys select v2b, SAM or v2b-first union, committed bank, score/dedup thresholds and optional
conveyor region/label filters. SAM proposals restrict fit candidates; synthetic category
markers never become exact asset identity hints. Existing fit acceptance and identity
stages remain. Series count accepts category-constrained masks, with the bank score
threshold for SAM and unchanged v2b count threshold. Route/request counts are recorded
under `_perception.sam.routing`; inactive tasks make zero SAM requests. Missing requested
services are infrastructure failures. Existing SAM foreground/point flags remain available.
Conveyor filters are proposed integration hypotheses; SAMBAKE did not measure them.

`scripts/dojo/queues/sam_shared.sh` manages the existing shared-side bundle and verifies
checkpoint hashes. Lanes require exact model match and PID/info health; no per-job SAM
is started. A single shared process counts once in the admission gates, actual residency
is included in nvidia-smi gates, and a separate explicit 12 GiB lane reservation opt-in
allows the measured single-checkpoint wave to share the box. Defaults retain the old gate.
Use one checkpoint per box/wave; drain before changing it.

## Compute3 service measurement

Torch 2.9.1+cu128, bf16, Meta f1647e8; server-only (no v2b), detector-only models,
6 torch threads, CPUQuota=600%, MemoryMax=10G, allocator capped to 30% of the 32GB card.
`who`/nvidia-smi checked first; `~/dojo-gpu-light8.lock` held. Own code/deployment under
`~/controlr-samint`, read-only checkpoints and permitted frame-zero pour 100005 RGB from
SAMBAKE. No GT was read. Existing `~/controlr-identity/.venv` supplied torch read-only;
a private dependency overlay supplied huggingface_hub 0.36.0 and SAMBAKE's vendored Meta code.
Raw socket results: [sam3](../experiments/data/samint/sam3.json),
[sam3.1](../experiments/data/samint/sam31.json), [both](../experiments/data/samint/both.json).

| Loaded service | model load / socket ready | torch peak allocated | nvidia-smi residency |
|---|---|---|---|
| SAM3 | 5.4 / 6.51s | 5.34 GB | 5964 MiB |
| SAM3.1 text | 4.4 / 5.51s | 5.64 GB | 6262 MiB |
| Both detectors | 8.9 / see raw JSON | 9.22 GB | 9684 MiB |

Each timing uses the **same** permitted RGB with different full banks; these are service
latencies, not new task-quality measurements. Three warm requests/bank, then two simultaneous
clients; whole-request model lock serializes them. Times include socket/image upload and masks.

| Service / bank | mean single request | simultaneous clients' request latency |
|---|---|---|
| SAM3 / pour | 374ms | 373 / 749ms |
| SAM3 / classify-language | 591ms | 601 / 1192ms |
| SAM3 / egg | 157ms | 152 / 298ms |
| SAM3.1 / pour | 368ms | 392 / 763ms |
| SAM3.1 / classify-language | 599ms | 585 / 1189ms |
| SAM3.1 / egg | 158ms | 155 / 312ms |

All owned server children terminated normally after measurement; no SAMINT GPU process
remained. Other GPU users changed during this measurement; this is a contention/readiness
benchmark, not a controlled machine comparison. Both-checkpoint residency is too high for
two 10–12GB camera lanes plus shared seg/glyph; use a single checkpoint per wave.

## Parked camera specs and overlap

Each gain cell has 20 owned fresh-salt pairs, plus 10 Xylophone strong and 5 classify parity
pairs. Sonnet 5.5 route, full per-writer refined audit with #417 persistent consumed identity.
No layout generation, frozen dispatch manifest or lane write has occurred. The documents
specify preparation/freeze requirements for the lead's allocation; they do not assert the
new hypotheses passed. Conveyor ROI proposals require RGB calibration review before dispatch.
